# Recording Troubleshooting

## Common Recording Issues

### Recording Not Starting

| Step | Action |
|------|--------|
| 1 | Check Matrox power |
| 2 | Verify storage space |
| 3 | Check input signal |
| 4 | Verify control command |
| 5 | Restart Matrox |

### Poor Recording Quality

| Step | Action |
|------|--------|
| 1 | Check input signal quality |
| 2 | Verify encoding settings |
| 3 | Check storage speed |
| 4 | Reduce resolution if needed |

### Recording Stops Unexpectedly

| Step | Action |
|------|--------|
| 1 | Check storage space |
| 2 | Verify power stability |
| 3 | Check for overheating |
| 4 | Review error logs |

---

## Matrox Specific Issues

| Symptom | Action |
|---------|--------|
| No power | Check power supply |
| No input | Check source, cable |
| No recording | Check storage, settings |
| File corrupted | Check storage integrity |
| No network | Check network connection |

---

## Storage Issues

| Issue | Action |
|-------|--------|
| Full storage | Clear old files, expand |
| Slow write | Check disk speed |
| File errors | Check disk health |
| Network issues | Verify NAS connection |

---

## Audio/Video Sync Issues

| Issue | Action |
|-------|--------|
| A/V out of sync | Check encoding settings |
| Audio missing | Verify audio input |
| Video stuttering | Check storage speed |

---

## Integration Issues

| Issue | Action |
|-------|--------|
| Wrong source | Check matrix routing |
| No control | Check Crestron connection |
| No audio | Check DSP output |
| Dual record mismatch | Verify sync settings |
