# Video Troubleshooting

## Common Video Issues

### No Video Signal

| Step | Action |
|------|--------|
| 1 | Verify source is powered on |
| 2 | Check cable connections |
| 3 | Verify matrix input selection |
| 4 | Test with known-good source |
| 5 | Check matrix output routing |

### Wrong Source Displayed

| Step | Action |
|------|--------|
| 1 | Verify matrix routing |
| 2 | Check input assignment |
| 3 | Confirm source device output |
| 4 | Re-route if needed |

### Poor Video Quality

| Step | Action |
|------|--------|
| 1 | Check cable quality/length |
| 2 | Verify resolution settings |
| 3 | Check for interference |
| 4 | Test alternative cable |

---

## Matrix Troubleshooting

### Extron 16×16

| Symptom | Check |
|---------|-------|
| No output | Power, input signal, output routing |
| Wrong output | Routing table verification |
| Intermittent | Cable, power, temperature |

### Crestron 8×8

| Symptom | Check |
|---------|-------|
| No output | Cresnet/IP communication |
| Wrong source | Input assignment |
| No control | CP4 connection |
