# Camera Troubleshooting

## Common Camera Issues

### No Video Output

| Step | Action |
|------|--------|
| 1 | Verify camera power |
| 2 | Check network connection |
| 3 | Verify video output cable |
| 4 | Test with direct connection |
| 5 | Check matrix input |

### PTZ Not Working

| Step | Action |
|------|--------|
| 1 | Check IP connection |
| 2 | Verify API access |
| 3 | Check Crestron control |
| 4 | Restart camera |

### Poor Video Quality

| Step | Action |
|------|--------|
| 1 | Check lighting |
| 2 | Verify resolution settings |
| 3 | Check lens cleanliness |
| 4 | Adjust camera settings |

---

## Cisco Camera Specific

| Symptom | Action |
|---------|--------|
| No power | Check PoE/adapter |
| No network | Check cable, switch |
| No video | Check output, matrix |
| PTZ failure | Check API, control system |
| Preset failure | Verify preset storage |

---

## Camera Positioning Issues

| Issue | Action |
|-------|--------|
| Framing off | Adjust position |
| Lighting poor | Adjust lighting |
| Focus issues | Auto-focus or manual |
| Shaky image | Check mounting |

---

## Integration Issues

| Issue | Action |
|-------|--------|
| No control from Crestron | Check IP, API |
| Wrong camera on display | Check matrix routing |
| Recording wrong camera | Check Matrox source |
| Presets wrong | Recalibrate positions |
