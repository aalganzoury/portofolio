# Audio Troubleshooting

## Common Audio Issues

### No Audio Output

| Step | Action |
|------|--------|
| 1 | Check source is active |
| 2 | Verify amplifier power |
| 3 | Check DSP processing |
| 4 | Verify speaker connections |
| 5 | Check mute status |

### Distorted Audio

| Step | Action |
|------|--------|
| 1 | Check gain structure |
| 2 | Verify speaker impedance |
| 3 | Check for clipping |
| 4 | Reduce input level |

### Low Volume

| Step | Action |
|------|--------|
| 1 | Check gain staging |
| 2 | Verify DSP output level |
| 3 | Check amplifier settings |
| 4 | Verify speaker wiring |

---

## DSP Troubleshooting (Bose ControlSpace)

| Symptom | Action |
|---------|--------|
| No output | Check input, processing, routing |
| Wrong audio | Check matrix routing |
| Feedback | Check EQ, gain, mic placement |
| Noise | Check cable, ground, interference |

---

## Microphone Troubleshooting

### Wireless Mics (Shure/Beyerdynamic)

| Symptom | Action |
|---------|--------|
| No audio | Check battery, frequency, range |
| Dropout | Check interference, range |
| Distortion | Check gain, battery |
| Cross-talk | Change frequency |

### Conference Mics (Televic)

| Symptom | Action |
|---------|--------|
| No audio | Check unit, cable, central |
| Wrong channel | Check language routing |
| Feedback | Check gain, placement |

## Amplifier Troubleshooting

| Symptom | Action |
|---------|--------|
| No output | Check input, power, protect mode |
| Protect mode | Check impedance, short circuit |
| Noise | Check input, cable, ground |
| Overheating | Check ventilation, load |

## Speaker Troubleshooting

| Symptom | Action |
