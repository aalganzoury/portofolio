AWS Cloud Infrastructure Project

Highly Available Web Application Architecture

Project Overview

A production-grade, highly available web application infrastructure on Amazon Web Services (AWS). This architecture demonstrates Multi-AZ deployment with automatic failover, horizontal scaling, and robust security implementation.

The infrastructure follows AWS Well-Architected Framework principles and is suitable for enterprise-grade web applications requiring high availability, scalability, and security.

VPC ALB Auto Scaling NAT Gateway Multi-AZ Security Groups

Architecture Components

  • VPC with CIDR 10.0.0.0/16 — Network isolation
  • Public Subnets (10.0.1.0/24, 10.0.3.0/24) — ALB, NAT Gateway
  • Private Subnets (10.0.2.0/24, 10.0.4.0/24) — EC2 Instances
  • Application Load Balancer — Layer 7 load balancing
  • Auto Scaling Group — Automatic scaling across 2 AZs
  • NAT Gateway — Outbound internet for private instances
  • Security Groups — Stateful firewall rules
  • Route Tables — Traffic routing configuration

Key Features

  • High Availability — 99.99% uptime SLA
  • Fault Tolerance — No single point of failure
  • Auto Scaling — 2-4 instances based on demand
  • Security — Public/private subnet separation
  • Multi-AZ — Redundancy across availability zones
